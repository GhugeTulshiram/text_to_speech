🤟 Sign Language Conversion System

 📌 Project Overview

Sign Language Conversion System is a full-stack web application developed to make communication easier through sign language. The system provides two main functionalities: **Sign to Text and Speech** and **Text to Sign**, both available on separate pages. In the Sign to Text and Speech module, the user shows a supported hand sign in front of the camera, the system recognizes the sign using Python and Machine Learning, displays the corresponding character as text, and converts that text into speech. In the Text to Sign module, the user enters a supported alphabet or digit and the system displays the corresponding sign. Currently, the project supports English alphabets from **A to Z** and digits from **0 to 9**, giving a total of **36 supported classes**. The application also includes a user authentication system with registration, login, and logout functionality. The frontend is developed using **React.js**, **JavaScript**, **HTML**, and **CSS**. The backend is developed using **Node.js** and **Express.js**, while **MongoDB** is used to store user and application data. The sign recognition functionality is implemented using **Python and Machine Learning**, where reference samples and datasets for the supported A–Z alphabets and 0–9 digits are used for recognition and classification. The Sign to Text and Speech feature captures the user's hand sign through a webcam, processes it through the sign recognition module, identifies the corresponding supported character or digit, displays it as text, and generates speech output. The Text to Sign feature works separately and converts supported text input into its corresponding sign representation. Unicode is used for standard character representation, for example, **A is represented as U+0041** and **5 is represented as U+0035**. The project currently focuses on individual alphabets and digits and does not yet support complete words, continuous sentences, or full sign language translation. The project structure consists of a React frontend, a Node.js and Express.js backend, a MongoDB database, and a Python Machine Learning module containing datasets, reference data, and recognition functionality. To run the project, first clone the repository using `git clone https://github.com/GhugeTulshiram/text_to_speech.git`, then start MongoDB, open the backend folder and run `npm install` followed by `npm start`, open another terminal, go to the frontend folder and run `npm install` followed by `npm run dev`, and finally open a third terminal, go to the Python ML folder, create and activate a virtual environment, install the required dependencies using `pip install -r requirements.txt`, and run the Python application using `python app.py`. The project aims to provide a simple, user-friendly, and accessible platform for converting supported sign language gestures into text and speech and converting supported text characters into sign representations. Future improvements may include support for complete words and sentences, additional sign language characters, improved recognition accuracy, multilingual support, voice input, recognition history, and a mobile application.
